Flash Page Changelog
====================

Version 1.0.4 (October 14, 2026)
-----------------------------------

Added:
- CSP Nonce Support: Added dynamic Content Security Policy (CSP) nonce injection for Speculation Rules via init({ nonce }) and data-flash-nonce attribute, ensuring strict CSP compliance without inline execution violations.
- Open Shadow DOM Traversal: Added event path traversal via event.composedPath() and collectAnchors helper to seamlessly detect and preload links encapsulated inside Web Components and open shadow roots.
- Parameter Matrix Expansion: Added parameter 21 (nonce) to the Master Parameters Matrix with full test suite coverage.

Changed:
- Touch Tap Normalization: Added tap timestamp tracking to suppress synthetic and duplicate mouseover events within 500ms of a touch tap on mobile devices (iOS Safari / Android Chrome).
- Enhanced Destructive Action Filtering: Extended security guards to automatically filter destructive query parameters (?action=delete, ?action=logout, ?do=delete, ?act=signout) in both JavaScript guards and Speculation Rules selector exclusion rules.
- Documentation: Updated README.md comparison table, WordPress enqueue snippet, and added Deep-Dive section for CSP nonce compliance.

Version 1.0.3 (October 1, 2026)
-----------------------------------

Added:
- Package Whitelist: Explicitly included Changelog.txt in package.json files array for npm tarball inclusion.
- Release Automation: Added automated release workflow (scripts/release.js and npm run release) to streamline version bumping, bundle rebuilding, testing, and git tagging.

Changed:
- Dynamic Versioning: Modernized test suites (test/unitTests.js and test/comprehensiveTests.js) and build script (scripts/build.js) to resolve package version dynamically from package.json.
- Workbench Evergreen: Updated test/live-test.html to use an evergreen workbench header, avoiding stale manual version strings.
- Distribution Bundles: Rebuilt all 4 universal bundles with v1.0.3 headers and updated TypeScript definitions.
- Documentation: Synchronized README.md version headers, WordPress enqueue snippet, and feature comparison tables to v1.0.3.

Version 1.0.2 (September 30, 2026)
-----------------------------------

Changed:
- Release Automation: Enabled npm provenance publishing with OIDC cryptographic attestation via Sigstore and GitHub Actions.
- CI/CD Runtime: Upgraded release workflow to Node 22 LTS to eliminate runner deprecation notices.
- Distribution Bundles: Rebuilt all 4 universal bundles with v1.0.2 headers and updated TypeScript definitions.
- Documentation: Synchronized README.md and test suites to v1.0.2.

Version 1.0.1 (September 29, 2026)
-----------------------------------

Fixed:
- Server Backpressure: Added robust Retry-After header parsing for numeric seconds and HTTP-date strings, with a 30s default fallback and 5-minute safety cap.
- Markov Storage Bounds: Capped the model to 50 source paths (a few KB at most) using LRU recency so local storage stays bounded.
- Markov Path Learning: Capped destinations to 5 per path and evicted the weakest existing destination so new links can be learned.
- Path Filtering: Replaced substring matching with path-segment regex so innocent URLs like /blog/how-to-remove-stains are not skipped.

Changed:
- Added instant.page vs Flash Page feature comparison table to README.
- Rebuilt all production bundles with v1.0.1 banners and updated TypeScript definitions.
